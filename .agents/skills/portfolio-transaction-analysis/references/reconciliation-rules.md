# 资金流水解析与对账规则手册 (Reconciliation Rules)

本手册总结了从券商/银行交易流水截图（如汇丰 Trade25、富途、老虎、盈透等）中准确提取并分类交易记录的经验法则。

---

## 1. 核心概念与防混淆矩阵

用户在查看资产统计时最容易产生的困惑是：**为什么买入总额远大于实际投入的本金？**

| 概念 | 定义 | 资金来源 | 影响指标 |
| :--- | :--- | :--- | :--- |
| **净投入本金 (Net Deposited)** | 外部真实存入账户的净现金：`∑外部入金 - ∑外部出金` | 外部银行账户、薪资、个人外部资金 | 折线图基准线、真实年化收益率分母 |
| **累计买入 (Gross Invested)** | 历史所有买入股票所花费的资金总和：`∑(成交额 + 佣金税费)` | 可以是初始入金，也可以是**卖出股票回笼的资金再次复投** | 交易规模/周转率，**绝不能**当成本金 |
| **换汇 (Currency Exchange)** | 账户内一种货币转换为另一种货币（如 CNY -> USD） | 账户内已有闲置现金 | **不增加**总投入，仅改变币种分布 |
| **总资产 (Net Worth)** | 当前全部币种现金余额 + 当前持仓股票市值 | 净本金 + 累计总盈亏 | 账户当前总清算价值 |
| **累计盈亏 (Total PnL)** | 已实现盈亏（平仓收益/亏损） + 未实现盈亏（浮动盈亏） + 股息利息 - 费用 | 资产价值变动 | 净资产与净本金的差额 |

### 核心恒等式
$$\text{总资产 (Net Worth)} - \text{净投入本金 (Net Deposited)} = \text{累计总盈亏 (Total PnL)}$$
若对账无误，上述公式必须在任意时刻精确成立。

## 2. 截图流水常见交易类型识别法则

在分析截图流水（如 HSBC Trade25 / 汇丰银行证券账单）时，应按下述特征严格分类：

### A. 外部入金 (Deposit)
- **特征文本**：`LI JIAHUI HC...`、`INWARD REMITTANCE`、`FASTER PAYMENT`、`BANK TRANSFER IN`、`FPS 汇款`。
- **正负特征**：金额为正（贷方入账），对应单一币种。
- **处理方式**：
  - 录入为 `kind = "deposit"`；
  - 金额 `amount` 为实际到账金额；
  - 备注记录完整的凭证号或流水号（如 `HC12622366279373`），便于日后审计。

### B. 内部换汇 (Currency Exchange) —— 最容易被误认为“入金/出金”
- **特征文本**：`FX CONVERSION`、`CURRENCY EXCHANGE`、`汇率兑换`、`凭证 N...`。
- **成对出现特征**：
  - 同一时间戳或同一天内，必有一笔**扣减币种 A**（出账）和一笔**增加币种 B**（入账）；
  - 往往带有相同的交易凭证号（例如 `N52944706418`）。
- **常见误区**：
  - **严重错误**：将增加的币种 B 记为 `deposit`（入金），把减少的币种 A 记为 `withdrawal`（出金）。这会导致本金虚高或虚假出金！
- **正确处理**：
  - 录入为单条 `kind = "exchange"` 记录；
  - `currency` 为支出币种（如 `CNY`），`amount` 为支出金额（如 `10,000.00`）；
  - `target_currency` 为换得币种（如 `USD`），`target_amount` 为换得金额（如 `1,474.83`）；
  - 汇率计算：`rate = target_amount / amount`。

### C. 证券买卖 (Buy / Sell)
- **特征文本**：`BUY`、`SELL`、`BOT`、`SLD`、股票代码（如 `TSLA`、`NVDA`、`00700`）、成交股数与单价。
- **买入 (Buy)**：
  - 扣除现金，增加持仓份额；
  - 计入 `grossInvested`（累计买入），**不影响** `netDeposited`（净本金）。
- **卖出 (Sell)**：
  - 减少持仓份额，增加现金余额；
  - 产生已实现盈亏，现金留在账户内供后续买入或出金。

### D. 股息与利息 (Dividend / Interest)
- **特征文本**：`CORP EVT PAYMENT SEC`（美股/港股分红派息）、`CREDIT INTEREST`（账户活期结息）。
- **处理方式**：
  - 录入为 `kind = "dividend"`；
  - 属于账户内生资产增加，**不计入**外部入金本金。

### E. 账户与托管费用 (Fee / Custodian Fee)
- **特征文本**：`CUSTODIAN FEE SEC`（证券存仓/托管费）、`ACCOUNT SERVICE FEE`。
- **处理方式**：
  - 录入为 `kind = "withdrawal"`（带特定说明）或独立扣费；
  - 属于投资净消耗，冲减现金余额。

## 3. 常见陷阱与注意事项

1. **垫资补扣零钱**：
   例如美股账户扣收 30 HKD 存仓费时，如果港币现金不足，系统会自动从美元兑换微小金额（如 `3.84 USD -> 30.00 HKD`）完成补扣。这类换汇也是标准的 `exchange`，切勿遗漏。
2. **重命名规范**：
   在 UI 和提示中，将“累计投入”明确命名为“**累计买入**”，将外部现金明确命名为“**净投入本金**”，防止用户产生理解分歧。
